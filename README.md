# Crab Kingdom

A Roblox Studio (Luau + Rojo) colony simulator project.

> **Repository status (Nov 2026):** This GitHub repository is an initial **Codex-ready specification scaffold**, not the full previously generated alpha source archive. The source files from the ZIP have not been uploaded here yet. Use Codex to implement the project from `AGENTS.md` and `docs/GDD.md`, or import the previous source separately when available.

## What to do in Codex

1. Open Codex and select the GitHub repository `eightstore/crab-kingdom`, branch `main`.
2. Ask Codex: **"Read AGENTS.md and docs/GDD.md. Build Phase 1 as a working Rojo + Luau project with a single crab that smoothly walks to a shell resource, picks it up, returns to the nest, deposits the resource and repeats. Include the required configs, scripts and test instructions. Commit the resulting code."**
3. Review Codex's changes, then extend economy, Royal Conch, inventory and tides in successive tasks rather than one gigantic generation.
4. Sync via Rojo in Roblox Studio and use Play / Start Server to verify runtime behavior.

See `docs/GDD.md` for requirements and `AGENTS.md` for coding standards. Codex cannot guarantee Roblox runtime success without Studio testing.
